High-Resolution PCB X-ray Component Detection & Automated Label Generation

A Computer Vision project focused on aligning CAD design information with 2D X-ray imagery, automatically generating component annotations, and evaluating object-detection models.

Problem & objective

High-resolution PCB X-ray images require carefully prepared labels for supervised component detection. The project investigated a CAD-assisted pipeline to map design information into image coordinates and support YOLO dataset preparation and model evaluation.

My documented contributions

  • Used ArUco markers, pixel-coordinate conversion, affine and homography transformations to align CAD and X-ray information.
  • Generated and validated YOLO-format component bounding boxes.
  • Prepared the dataset from 126 original X-ray images containing 2,285 annotations across nine component classes.
  • Trained and compared six YOLO models (YOLO11/12/26 variants), including examination of augmentation and prediction errors.

Reported outcome

Among the evaluated models, YOLO12s reached 80.35% mAP50–95 on the held-out test subset, according to the completed project summary. This is a project-specific result, not a claim of generalizable production performance.

Scope and limitations

The completed work concerns component detection and label generation. It should not be described as validated defect diagnosis. The pipeline operated on 2D X-ray images; camera-intrinsic calibration data was not required for the reported object-detection evaluation. Accurate measurements in physical units would require suitable geometric scale/reference information.
